# Gaz AI — first combined release

This release keeps the native Truth Detective workspace and Endless Investigation question tree together in the main app.

Included:
- Evidence ledger and connection map
- Endless Investigation question tree with locally saved branches and answers
- Save Endless Investigation answers to the evidence ledger, with duplicate protection
- Phone readability improvements for investigation inputs and controls
- Android instrumentation coverage for question persistence, follow-up parsing, and evidence saving

AI-generated answers remain research leads and should be checked against original sources.
